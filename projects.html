    Which Card? - Credit Card Reward Picker

    Live Demo

    • Product Design
    • Expo
    • React Native
    • TypeScript
    • Supabase
    • LLM App
    • GitHub Actions
    • Deployment
    • Designed and shipped a bilingual (Traditional Chinese and English) web app that ranks a user's credit cards for any merchant or category at checkout, factoring in point valuations, quarterly rotating categories, and custom spending categories and points programs defined by the user.
    • Built wallet management (catalog and custom cards, editable reward rules), statement-credit tracking, and a wishlist with issuer links on top of a Postgres-backed US card catalog that updates without a new release.
    • Added receipt and sign scanning: QR codes are decoded in the browser, and otherwise a Groq vision model reads the merchant, total and category. Unknown stores are categorized by an LLM through Supabase Edge Functions.
    • Implemented Google sign-in with cross-device sync and in-app account deletion on Supabase (row-level security on every table), plus a welcome demo and a stateless guest mode for signed-out visitors.
    • Automated upkeep with GitHub Actions: a monthly job checks every card's issuer page and proposes catalog changes for manual review, and a daily job emails users about statement credits expiring in 3 days through Resend.
    • Deployed the Expo web build to Vercel with Sentry error reporting, from a single codebase shared with future iOS and Android targets.
